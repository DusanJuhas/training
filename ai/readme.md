# 10_Layers_AI_Assistant_EN_CZ.pptx Presentation Summary

The presentation explains the 10 layers required to build a production-ready AI assistant using the example of an internal customer support assistant. It walks through the technical foundation, beginning with embeddings, vector databases, RAG, and large language models that enable the assistant to understand company documentation and answer questions accurately.

# The_Python_AI_Stack.pptx Presentation Summary

A 47-slide deck about the 34 Python libraries a single AI project can touch. They are grouped into 10 layers that roughly follow a project's lifecycle. Each library gets one slide with its logo, a short description of its purpose, key features, the `pip install` command and a minimal code sample.
